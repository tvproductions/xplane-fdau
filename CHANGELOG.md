# Changelog

All notable changes to this project are documented here.

## 0.1.0

- Initial public release of the capture-neutral native X-Plane FDR toolkit.
- Read FDR v3/v4, write canonical v4, record push-first samples, validate
  strict recording configuration, and export GeoJSON.
- Provide offline `inspect`, `validate`, and `to-geojson` commands.
