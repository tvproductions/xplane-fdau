# Superseded Exploratory FOQA/FDR Illustration

This Gemini-derived document was an exploratory system illustration, not a
reviewed implementation or standards specification. Its useful architectural
imperative has been retained and substantially expanded in:

- [X-Plane 12 Virtual FDAU/FDIU Ecosystem Design](xplane12_virtual_fdau_ecosystem_design.md)

The replacement corrects the project boundary from a narrow `xplane-fdr`
library to a virtual FDAU/FDIU acquisition and distribution core, preserves the
native X-Plane FDR implementation as a format/sink kernel, defines the q4xpcc
integration boundary, and removes unsupported ARINC, FAA, QAR, FDR, FOQA,
threshold, privacy, and certification claims.

Do not use an earlier revision of this file as normative project guidance.
